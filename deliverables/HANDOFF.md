## How to build and run

Prerequisites: Verilator 5.053+, UVM 1.2 source, g++ 12+.

    export UVM_DIR=/path/to/uvm-1.2
    cd winning_testbench
    ./build_uvm.sh

    # Golden RTL (should PASS)
    ./.uvm_smoke/Vqpsk_tb_top +UVM_TESTNAME=qpsk_base_test \
                              +CHSEED=42 +SVSEED=42 +CELL=golden
    # Expected: [RESULT] PASS

    # A Sabotage mutant (should FAIL)
    ./.uvm_smoke/Vqpsk_tb_top +UVM_TESTNAME=qpsk_base_test \
                              +CHSEED=42 +SVSEED=42 +CELL=S-01_const_sym10_i
    # Expected: [RESULT] FAIL errors=10
